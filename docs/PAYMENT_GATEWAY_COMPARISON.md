## 🔄 Migration Guide (If You Want to Switch)

### From Razorpay to Cashfree

**Changes Needed:**

1. **Update CDN:**
```html
<!-- Replace -->
<script src="https://checkout.razorpay.com/v1/checkout.js"></script>
<!-- With -->
<script src="https://sdk.cashfree.com/js/v3/cashfree.js"></script>
```

2. **Update JavaScript:**
```javascript
// Razorpay
const options = {
  key: 'rzp_test_xxx',
  amount: 49900,
  // ...
};
const rzp = new Razorpay(options);
rzp.open();

// Cashfree equivalent
const cashfree = new Cashfree({
  key: 'cf_test_xxx'
});
cashfree.checkout({
  orderAmount: 499,
  // ...
});
```

**Effort:** 2-3 hours

---

### From Razorpay to Instamojo

**Option 1: Payment Links (No Code)**
1. Create payment link in Instamojo dashboard
2. Replace Buy button with link
3. Done!

**Option 2: API Integration**
```javascript
// Redirect to Instamojo
window.location.href = 'https://test.instamojo.com/@yourusername/payment-link';
```

**Effort:** 30 minutes (links) or 2 hours (API)
